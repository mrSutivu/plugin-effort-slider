🎚️ Effort Slider for DeepSeek Harness — a notched reasoning-effort slider grouped with the model picker, right in the composer.

Codex / Claude-Code style, but native DSH: direct model list (no submenu), realtime notched drag, max-effort "deep diving" shimmer, themeable via DSH variables, EN/FR/ZH. Zero core changes, MIT.

👉 github.com/mrSutivu/plugin-effort-slider

Install:

```sh
dsh plugin --profile web add github:mrSutivu/plugin-effort-slider
```
