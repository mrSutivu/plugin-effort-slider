🎚️ 给 DeepSeek Harness 做了个 Effort Slider 插件 —— 把模型选择和推理强度滑杆做进输入框里的同一个胶囊。

对标 Codex / Claude Code，但原生 DSH 风格：模型直选（无中间菜单）、带刻度的实时拖拽、最高档有 deep diving 呼吸渐变、跟随 DSH 主题变量、中英法三语、不改核心代码，MIT 开源。

👉 github.com/mrSutivu/plugin-effort-slider

安装：

```sh
dsh plugin --profile web add github:mrSutivu/plugin-effort-slider
```
